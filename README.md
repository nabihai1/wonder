# Wonder
Every child deserves to experience the wonder of reading. 
# Goal
Wonder is an extension that helps children ages 4-14 read better.
# Summary
Wonder is single-page reader that includes a read-aloud with word highlighting. A user can put in files and their own documents for it to be processed into a format that is easier for children with disabilities to read. Our targeting audience is children ages 6-14 who have visual impairment such as nystagmus and CVI (Cortical visual impairment), dyslexia, ADHD, and autism.
